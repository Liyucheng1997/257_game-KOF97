# 拳皇 97 · 风云再起（同人自制格斗引擎）

一个从零写的 2D 格斗游戏引擎，目标是**还原 KOF'97 的手感**：60fps 定帧逻辑、逐帧判定框、
小跳/大跳、前冲/后跃、翻滚、必杀指令识别、招式取消、顿帧（hitstop）、能量槽与 MAX 爆气。

画面是**程序化生成**的（骨骼动画角色 + 视差舞台 + 打击特效 + WebAudio 合成音效与 BGM），
不包含任何原版 SNK 美术资源。想换成真素材的话，见文末「换成自己的贴图」。

纯前端，无依赖，无需构建。

[在线试玩](https://liyucheng1997.github.io/257_game-KOF97/) · [v1.1.0 发布记录](https://github.com/Liyucheng1997/257_game-KOF97/releases/tag/v1.1.0)

## 运行

因为用了 ES Module，需要通过 http 打开（直接双击 `index.html` 会被浏览器的 CORS 拦掉）。

```bash
python -m http.server 8248
```

然后浏览器打开 <http://localhost:8248>，选择角色、对手与场景，然后点击“开始对战”。

### 连段思路

- `蹲B → 蹲A → 必杀`：轻击之间可以互相取消，轻击可取消进必杀。
- `近身C → 必杀 / 超必`：重击只能用必杀技取消，不能再连普通技。
- 例：八神 `蹲B → 葵花 ①→②→③`（4 段）；京 `近C → 荒咬み → 毒咬み`。

## 引擎里都做了什么

- **定帧逻辑**：固定 60fps 步进，渲染与逻辑分离，掉帧不影响判定。
- **逐帧判定框**：每招的攻击框写明生效帧区间（`framedata.js`），`F1` 可视化。
- **顿帧 + 震屏**：命中按力度冻结 8~22 帧，超必带 26~34 帧定格与放射线。
- **输入系统**：
  - 指令识别带容错分支，623 写严于 236，避免升龙和波动互抢。
  - 组合键让位：按下单键后延迟 2 帧确认，期间凑齐 `A+B` / `C+D` 就交给组合技。
  - 输入缓冲按「可行动帧」计时，顿帧不消耗缓冲 —— 打中的瞬间按取消一定接得上。
  - 前冲/后跃只认正横向连打，且中间必须回中，所以 214214 不会误触发后跃。
- **伤害补正**：连段每多一段伤害递减 8.5%，下限 32%。
- **防御规则**：下段必须蹲防、中段必须站防，空中不可防御（97 规则）。
- **能量系统**：3 格能量，出招/命中/被打/防御都涨气，MAX 爆气期间不涨气。
- **眩晕**：短时间内累计受创会 STUN。
- **AI**：4 个难度档，走和玩家完全相同的指令识别管线（AI 只是往手柄里写方向和按键），
  会防御、对空、抓硬直惩罚、取消连段、放超必。

## 换成自己的贴图

引擎默认走程序化渲染，但留了贴图管线：只要 `assets/manifest.json` 存在就自动接管，
可以只替换一部分动作，没配到的动作会自动回退到骨骼渲染。

```
assets/
  manifest.json
  kyo.png
```

`manifest.json`：

```json
{
  "kyo": {
    "sheet": "kyo.png",
    "scale": 1,
    "anchor": "feet",
    "clips": {
      "idle":  { "loop": true,  "fps": 12, "frames": [[0,0,80,110],[80,0,80,110]] },
      "walkf": { "loop": true,  "fps": 14, "frames": [[0,110,80,110]] },
      "stA":   { "loop": false, "fps": 20, "frames": [[0,220,96,110],[96,220,96,110]] }
    }
  }
}
```

- `frames` 每项是精灵表上的 `[x, y, w, h]`。
- clips 的键名 = 角色的 `state`（`idle` `walkf` `walkb` `crouch` `run` `air` `guard` `hit` `down` …）
  或 `moveId`（`stA` `crD` `jC` `oniyaki` `orochinagi` …，见 `framedata.js`），`moveId` 优先。
- 锚点是**脚底中心**。
- 帧数据和判定框仍然由 `framedata.js` 决定，换贴图不会改变手感；
  贴图和判定对不上的话，调 `framedata.js` 里对应招式的 `box`。
