# 原版素材接入

当前 manifest.json 为空，人物和场景回退到自制绘制。接口已就绪不意味着已有原版素材。

把精灵图与场景图放在本目录。以下只是格式示例，不存在的图片不会被下载：

```json
{
  "characters": {
    "kyo": {
      "sheet": "kyo.png", "scale": 1,
      "clips": {
        "idle": {"loop": true,"fps": 12,"frames": [[0,0,96,112,48,111]]},
        "stA": {"loop": false,"fps": 20,"frames": [[96,0,128,112,48,111]]}
      }
    }
  },
  "stages": {
    "0": {"image": "street.png", "scale": 1, "offsetY": 0},
    "1": {"image": "temple.png", "scale": 1, "offsetY": 0},
    "2": {"image": "harbor.png", "scale": 1, "offsetY": 0}
  }
}
```

精灵帧为 `[源x,源y,宽,高,锚点x,锚点y]`，后两项可省略，默认为脚底中心。左右翻转围绕锚点进行；不等宽攻击帧应明确填写同一脚底位置。动作键匹配 `moveId`，其次匹配 `state`。未提供的动作仍使用程序骨架，不能拿单张站姿替代全部攻击帧。

场景绘制到320×224画布，人物脚底位于y=196；用offsetY对齐地板。宽场景根据镜头平移，当前接口为单层图片，不支持原版场景各层逐帧动画。旧版角色直接放在顶层的manifest格式仍兼容。

完成精确还原还需：指定风云再起修订版、完整角色与隐藏角色数据、逐动作图片/持续帧/锚点、受击及攻击判定框、取消窗口、指令容错、招式音效、地图动画以及3对3队伍规则。现有角色数值不能视作原版数值。
